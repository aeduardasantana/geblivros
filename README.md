# GEB Materiais

Central de páginas individuais para materiais do GEB.

Domínio: `materiais.grupoeduardabispo.com.br`

Contato: `contato@grupoeduardabispo.com.br`

## Princípio de arquitetura

O GEB Materiais não funciona como um portal ou catálogo comercial. Cada material possui sua própria landing page e URL direta.

A raiz existe apenas como acesso técnico ao mapa geral de páginas.

## Padrão de URLs

- `/livro/[slug]`
- `/guia/[slug]`
- `/cartilha/[slug]`
- `/checklist/[slug]`
- `/planilha/[slug]`
- `/modelo/[slug]`
- `/kit/[slug]`
- `/relatorio/[slug]`
- `/estudo/[slug]`

## Mapa

`/mapa/` é o índice geral para localizar todas as páginas publicadas no projeto.

Sempre que um novo material for publicado, sua landing page e seu endereço devem ser adicionados ao mapa.
